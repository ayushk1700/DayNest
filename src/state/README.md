Schema-8 types with strict validation and explicit v0–v7 migrations. Conditional actions, repository locking and bounded history preserve independent edits. Scratchpad stores validated, customizable idea graphs; Wellbeing stores optional shared settings and a bounded actual-timer ledger after opt-in; Link Groups store validated web shortcuts locally. Recording, clear and automatic events stay outside undo. Draft recovery remains memory-only. Display ticks do not write storage.
