# Local widgets, media and live weather

Clock shows local device time/date and persists its 12/24-hour preference and face. Choose Simple, Digital alarm clock or Rounded analog from the card's Clock style selector or Customize. Digital uses local SVG seven-segment numerals, a cream sculpted case and an olive LCD; analog uses a sage squircle, cardinal ticks, live hour/minute/second hands and a red hub. Decorative case details are not alarm controls. Reminder remains the alert widget. Both physical faces scale to the existing 240 by 180 minimum; new clocks start at 300 by 280. Accessible timer text supplies the complete time without announcing every second. Multiple clocks are independent.

Notes offers Plain, Lined, Grid, Dotted and Kraft paper through Notes paper on the card and in Customize. CSS patterns scroll with the textarea, and Kraft adds a subtle bundled grain. Changing paper keeps the same draft editor, text, card geometry and colors. Custom colors retain calculated text contrast and disable the Kraft grain. Style selectors save immediately, separately from the appearance form's Save appearance button.

Clock style and Notes skin are optional strict schema-4 settings. Existing clocks without a style retain Simple; existing Notes uses ruled=true as Lined and ruled=false as Plain. Explicit Notes skins keep the legacy ruled flag consistent. Conditional actions protect concurrent same-field edits, preserve unrelated format/text changes, and participate in history, portable backups and recovery. No schema migration rewrites existing content or layout.

Habit Tracker supports local habits, daily toggles and the last seven local calendar days of history; dates use local year/month/day rather than UTC slices. Older completion dates remain stored when they scroll out of that seven-day window.

Calendar uses a cream/cyan glow, bold numbered month, outlined weekday strip, marked event dates, monthly agenda and stacked real year. New calendars start on Sunday to match the reference; existing preferences are retained and Calendar week starts offers Sunday/Monday. Month navigation, today/selected-day indicators, arrow-key day movement and event create/edit/delete remain local. The agenda shows real events for the displayed month, ordered by date/title; there are no seeded holiday or party events. Its small edit/delete icons remain directly accessible. Calendar has no remote account integration.

All fifteen picker entries, including separate Date and Video widgets and Link Group, create independent instances with sensible content and dimensions. There is no premium gating. Existing move/resize, zoom, stacking, rename, customization, pinning and widget deletion controls apply to the new widgets.

## Image storage
Image bytes are separate IndexedDB records in purrductivity-assets / images. The dashboard document stores only asset IDs and captions. Upload supports PNG, JPEG and WebP up to 5 MiB, at most 12000 pixels per side and 40 million pixels total. The implementation checks file signatures against MIME type, decodes the image and validates dimensions before saving. SVG/HTML and other executable formats are not accepted. Persisted blobs are checked before use. Caption and contain/crop-to-fill preferences persist. Object URLs are revoked on replacement/unmount. Upload/transaction failure or stale attachment leaves the prior image reference unchanged; a missing/corrupt image shows recovery guidance.

Assets are saved before their reference is committed. Cleanup takes the dashboard's Web Lock, reads and validates current references, protects references in the most recent valid recovery copy, and deletes only unreferenced assets at least 24 hours old. Recent/in-flight uploads are protected by that grace period. If the recovery copy cannot be validated, cleanup conservatively skips deletion. Automatic cleanup runs when image references change or the dashboard starts; the Image card also offers manual cleanup. This is not periodic background deletion. Stage 8 now additionally skips cleanup while any tab holds live undo/redo history. Portable import stages fresh asset IDs and preserves the recovery dashboard references. See backup-history.md.

Browser preview and the installed extension have separate origins and separate image databases. Removing an image clears its document reference; disk bytes can remain until eligible safe cleanup. A failed new attachment can leave a temporary unreferenced asset, which is cleaned later.

### Polaroid presentation
The Image widget now uses a warm paper matte, a small locally rendered grain texture, a larger photo opening, a handwritten multiline caption and a decorative underline. Desktop cards have a subtle static tilt and broad shadow; narrow layouts keep them straight. The title remains accessible in the top matte, with the existing three-dot menu. Replace, remove, fit and safe-cleanup controls appear over the photo on hover or keyboard focus and stay visible on touch devices. Empty cards offer a local upload button. Small cards reduce caption and empty-state decoration to preserve the photo space.

This is a presentation change: existing image bytes, captions, fit settings and positions are preserved. No reference artwork is added to a user's dashboard. Global/per-card borders, paper colors, corners, shadows and pinning still apply; custom paper colors disable the decorative grain and retain automatic text contrast. The system handwriting font falls back locally without a remote font request.

## Weather
Open-Meteo supplies live current conditions and seven daily high/low forecasts. City selection is manual and saved locally; the city is sent to the geocoding API and resolved coordinates to the forecast API. The UI discloses this and links to Open-Meteo. No GPS permission is requested. The manifest and connect-src allow only the two exact Open-Meteo API hosts. Photos, videos, backgrounds and other dashboard content are never sent to them.

The warm weather design uses a soft golden glow, large condition/temperature text, an editable city pill, persisted Celsius/Fahrenheit controls and seven icon/high-low pills. Forecast dates and today follow the selected city's timezone. Empty/error temperature is an em dash. Compact heights hide the forecast strip while retaining current conditions and controls. Failed or aborted city requests cannot replace a newer city's result. A failed same-city refresh retains the last on-screen reading with an explicit message. Unit changes convert locally, use conditional saved actions and participate in history.

Responses are cached in memory for 15 minutes, with manual refresh and visible-widget online/focus/periodic reconciliation. A fresh offline tab cannot fetch weather, while local widgets/media remain available. Requests time out after 15 seconds and malformed/rate-limited responses stay explicit. See weather-provider.md for primary service documentation, request details, validation and commercial-release considerations.

## Video Polaroid
Choose **Video** in Add Widget. The Polaroid frame accepts local MP4/WebM clips up to **25 MiB, five minutes, 4096 pixels per side and 9 million pixels total**, with codecs supported by the browser. Headers, metadata, dimensions, duration and decode support are checked before attachment; invalid replacement keeps the current clip. Caption and contain/crop preferences use the same conflict-safe actions as images. Native controls provide play, pause, seek, volume and fullscreen; nothing autoplays. Toolbar actions sit above the playback controls.

Video blobs share the existing local IndexedDB asset store. IDs stay in the dashboard document; object URLs are revoked on replacement/unmount. Local playback works offline after restart. Portable export/import and reset/recovery include the bytes, stage fresh IDs and preserve prior media. Cleanup protects current, recovery and history references and the existing 24-hour upload grace period. A non-decodable or non-seekable format may need conversion before use.

## Dashboard image
Settings contains **Dashboard background**, after card customization. Upload a local PNG/JPEG/WebP up to 5 MiB, choose fill/contain and softness, then **Save background**. The preview is a draft until saved. Same-field conflicts retain the draft. A missing image falls back to the theme canvas with guidance; the rest of the dashboard is retained. No remote image URL is fetched.

The background is part of schema 4 and history/backups/recovery. Its ID is included in the same protected asset reference set as photos/videos. Default migration adds no background and preserves prior content, geometry, styles and pins. Reset restores the theme canvas after saving recovery. Portable backups have an overall 50 MiB limit; many large clips can exceed it and export then reports an error without dropping media.

## Date banner
Choose **Date** in Add Widget. The warm, rounded banner follows the typographic reference: bold "It's", a large day with a raised ordinal ending, and a light month name. The displayed date always follows the device's current local date; no sample date is stored. An accessible time label uses the device locale and its machine-readable date uses the local calendar key. The visible sentence is English to match the reference. Live ticks do not write storage or create history entries.

Each banner has independent identity, title, geometry, appearance and pin state, with empty settings/content objects. Date was added in schema 3 and is retained by schema 4 migration; schemas 0/1/2 reject the newer type. Creation/deletion and appearance/layout changes use the normal history, backup and recovery flows. Default size is 600 by 240, with a 280 by 180 minimum; narrow layouts retain desktop geometry and wrap readable typography. Custom paper colors remove the decorative glow while retaining automatic contrast.

## Link Group

Choose **Link Group** in Add Widget to make a named collection such as Work, Study or Reading. Add up to 18 shortcuts per group; each one has a label, web address, built-in icon and tile color. The card shows them as a responsive grid of labeled app-style tiles. Select a tile to open its site in a new tab, or use its pencil button to edit or remove it. Rename the group from the card menu.

Shortcut data stays in the local dashboard and participates in history, portable backups and recovery. Only `http` and `https` web addresses are accepted; an address without a scheme is saved with `https://`. Icons are bundled locally, so the widget does not request remote favicons. It does not open a site until the user selects that shortcut. Schema 8 adds the validated link data and migrates older dashboards without creating or changing any shortcuts.

Tests in date-weather.test.mjs cover all ordinal endings, local midnight/year/leap-day transitions, strict date data, saved round-trips/history/backups and weather unit conflicts/history. The isolated Edge check in scripts/check-date-weather.mjs additionally verifies actual picker creation, midnight updates, reload, city/units, unavailable-data states, pinning and desktop/narrow presentation.
