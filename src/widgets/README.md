Fourteen widget types are dispatched by WidgetContent: Todo, Notes, Sticky, Pomodoro, Reminder, Clock, Habit, Image, Calendar, Weather, Date, Video, Scratchpad and Wellbeing. DashboardWidgets renders workspace instances with shared movement/resize and card actions; ambient notes use their separate workspace. Scratchpad has a local graph editor with plain-text drafts, connections, search, pan/zoom, list view and conditional undo. Wellbeing offers optional local timer recording, daily charts/tables, retained session time, break completions, explicit goals and current habit dates. Older completion counts never become inferred duration. Core content uses DraftField for conflict-aware autosave. Weather uses the configured Open-Meteo provider after a city is entered. See docs/insight-stage-1.md, docs/local-widgets.md and docs/timing.md.
