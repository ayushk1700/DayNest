The module worker is bundled as dist/background.js and imports local shared chunks. It uses storage and alarms and treats notifications as optional; the worker itself performs no weather requests. The extension manifest grants the dashboard access to the two exact Open-Meteo hosts and restricts connect-src accordingly. All writers use the repository/Web Lock protocol. See docs/timing.md for reconciliation and at-most-once notification delivery limitations, and docs/weather-provider.md for network disclosure.
